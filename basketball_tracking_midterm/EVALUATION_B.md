# 実験B：追加学習済みYOLOv5sの評価

実行日：2026-10-26。ユーザーがColabで学習・val・export・最終testを実施し、Windowsへ配置したモデルを使用しました。
experiment10の全2,512フレームを処理し、保存動画とログのフレーム数、時刻、候補からの最終選択、再評価の一致を確認しました。

## 入力と実行条件

- モデル：従来のYOLOv5s v7.0、1クラス `0: ball`。
- 重みSHA-256：`e9591189566b289a8488e63e38d5f285fafb4c7dc3afbc023ea2f3db33d12b7e`。
- 学習run：`runs/s/20261026T080653932076Z`。学習環境はColabのTesla T4。
- 配置された重み・学習metadata・val結果のSHA-256が、export記録と一致。
- 入力960、confidence 0.25、NMS IoU 0.45、FP32。保存候補のconfidence floorは0.001。
- `final_selection.json` の既存設定を採用。experiment10を見て閾値を調整していません。選択メモは「sのモデル。初期からの変更なし」で、閾値の最適化済みという意味ではありません。
- Windows側の `configs/experiment.json` は `selection_split` を `val` に変更。数値設定は既にexportと一致していました。
- 実験Bは全フレームでYOLOを実行し、confidence以上の候補の最高信頼度1個を出力。ByteTrack・KCF・過去位置を使いません。
- Windows 11、RTX 3050 Ti Laptop GPU 4GB、専用Python 3.12.2、PyTorch 2.5.1+cu121、OpenCV 4.10.0。
- 動画描画・保存あり、検出／画像キャッシュなし、実時間待機なし、Pythonのインターネット接続を拒否するoffline guardあり。

動画は1280×720、30fps、83.733333秒です。位置評価可能1,883フレームを精度の分母とし、確認済み不可視629フレームは位置不明として除外します。
ユーザー確認によれば学習元experiment11／12とは別撮影で、同じプレーの重複もありません。

TSRは未出力も失敗に含みます。CLEは出力がある全1,665フレームで算出し、誤対象への出力も含みます。未出力の218フレームはCLEには含まれません。
生の検出評価は候補を1対1で正解と対応付けます。最高信頼度1個を評価する最終出力のTSRとは評価対象が異なります。
不可視区間には157フレームで出力がありましたが、位置が不明なためFPとは断定していません。

位置評価可能な連続区間内で、IoU<0.5の最長連続時間は0.667秒、未出力の最長連続時間は0.333秒でした。
不可視・未注釈・segment境界で区切るため、遮蔽をまたぐ真の復帰時間ではありません。シュート／編集境界の詳細注釈もありません。

処理時間には読込・推論・描画保存・ログ・計測を含み、モデル準備・ウォームアップ3回・終了後の評価／グラフ作成は含みません。
83.733秒の動画処理に94.409秒かかったため、この1回の測定では実時間30fpsに達していません。撮影から表示までの遅延や15分の安定性は未測定です。

同じ動画・GT・入力サイズ・検出閾値・精度モード・描画設定であることを比較スクリプトで確認しました。
この動画ではTSR@0.5が約61.29ポイント上がっており、追加学習済みモデルの位置出力は未調整モデルより改善しています。
CLEの対象件数は条件ごとに異なるため、出力率・TSRと併記して解釈してください。

Aは以前の別時刻の測定です。比較CSV／グラフには記録済みfpsも含まれますが、PCの電力状態・負荷などを揃えた反復試験ではありません。
Aの10.11fpsとBの26.61fpsの差を、そのまま追加学習による高速化の効果とは結論しません。
また、これは1動画の評価であり、別試合・別体育館全体への性能を保証しません。C〜Eの比較は未実施です。

## 確認した出力と失敗例

120フレームの動作確認後、全動画を別runで実行しました。全動画の出力に対して次を確認しました。

- 保存動画を最後までデコードし、2,512フレーム、1280×720、30fpsを確認。
- candidates／trackingのJSONL、tracking／timing／per_frameのCSVがすべて2,512フレーム分あることを確認。
- frame_id、元動画時刻、毎フレームYOLO実行を確認。
- 全最終矩形が、そのフレームのconfidence以上の最高信頼度候補と一致。正解ラベルに基づく候補選びはしていません。
- 保存済み予測から検出・追跡指標を再計算し、初回のmetrics.jsonと完全一致。
- 保存動画の先頭フレームと時系列グラフを目視確認。緑が正解、橙が最終出力。
- frame 35（1.167秒）の代表失敗例では、正解のボールから離れた背景側の人物付近へ矩形が移っていることを目視確認。低IoUの代表フレームは計8枚保存。
